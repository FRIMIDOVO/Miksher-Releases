# Miksher

*DIY-контроллер* для управления звуком, **OBS** и **MIDI**. Упрощает работу с громкостью, стрим-софтом и многим другим.

## 🎛️ Что умеет

- Управление громкостью системы и отдельных приложений
- Переключение треков
- Mute звука / микрофона
- Управление громкостью источников в OBS
- Универсальный MIDI-режим для поддерживаемых программ *(в разработке)*
- Настройки под себя: бинды, уведомления

# 🧪 Как сделать плату (метод ЛУТ)
Есть файл `Mask/Board.lay`. Он содержит полную трассировку платы, которую можно распечатать с помощью как раз таки приложения Sprint-Layout. Что бы это сделать нужно:
1. Скачать через установщик, находящийся в этой же папке, или с интернета, если желаете, приложение для трассировки плат.
2. Открыть файл с трассировкой через эту программу.
3. Найти в левом верхнем углу кнопку Файл, нажать, затем, в открывшемся меню нажать Печать. Печатать с такими параметрами:
    - Слой K2, M1 ЗЕРКАЛЬНО
    - Слой K2, M2 НЕ зеркально
    - Также советую печатать на формате A5 глянцевой бумаги (фото бумаги): вместится оба рисунка
4. Затем все действия по методу ЛУТ(зашкурить, обезжирить, утюгом)
5. Протравить (я делаю в растворе FeCl3)
Поздравляю! Плата готова, осталось зачистить от чернил принтера, залудить, спаять.

## 🧰 Как пользоваться

Основной исполнительный файл — `Python_code/main.py`.  
Для его работы необходима папка `data` рядом (желательно с иконками, иначе их просто не будет).  
Остальные рабочие файлы создаются автоматически.

## 📜 Логирование

Для записи логов в `Python_code/data/logs.log` в файле `Python_code/core/config.py` установите аргумент `logs_in_file=True`.  
При желании можно изменить `level=logging.INFO`, чтобы не засорять файл логов.

## ⚙️ Настройки

Сейчас можно полноценно настраивать **уведомления**.  
Для этого запустите `Python_code/settings_main.py` и нажмите «Настройки уведомлений».  
Остальные настройки пока в разработке, но начало положено.
